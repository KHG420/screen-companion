画质、声音与连接详情

调整自己共享的画面；分辨率、帧率、码率独立设置。按比例适配竖屏，不拉伸或放大低分辨率源。

手动修改尺寸或帧率会锁定该项；预设重新填写参数与锁定状态。

参数为目标上限，实际能力取决于共享源、编码器和网络。4K / 60 FPS 不保证同时达到；静止画面可能降低发送帧率。锁定项不主动降档，码率仍是上限，拥塞控制始终生效。浏览器不支持锁定时会明确报错，不会偷偷改用其他策略。

共享声音：优先使用 Chrome / Edge，选择标签页并勾选“同时分享音频”。其他共享方式取决于浏览器和系统。
