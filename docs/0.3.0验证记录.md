# 同屏 0.3.0 验证记录

日期：2026-09-25。范围：电脑浏览器与安卓双人屏幕共享的画质、帧率与码率调节。保留批准的两只小狗视觉和设备直连优先、coturn 备用架构；未新增生产依赖、服务或信令协议字段。

## 交付功能

- 最高 3840×2160 目标；横竖屏按长短边等比例适配。低分辨率源不放大。
- 1–60 FPS 任意整数，与分辨率、0.5–80 Mbps 码率上限独立调节。
- 均衡、文字清晰、动态流畅、4K 超清预设；自动平衡、清晰优先、帧率优先策略。
- 通话中应用参数，实际发送/接收尺寸、区间 FPS、Mbps 与性能限制可见。
- 无效参数拒绝；设备拒绝组合时恢复原参数，恢复失败停止画面并保留语音。
- Android 采集源通过 VideoSource.adaptOutputFormat 限帧，编码器同时设置 maxFramerate。仅给 ScreenCapturerAndroid 传 FPS 不足以限制实际发送。
- 版本名 0.3.0，versionCode 4，测试签名 APK。

## 验证边界

本机桌面没有可用物理麦克风，浏览器使用受控 Canvas/正弦波输入；4K 解码证明传输及解码链路可用，不替代真实 4K 显示器采集验收。安卓使用官方模拟器的真实 MediaProjection 录屏。模拟器不能替代不同品牌手机、Windows/Linux 实机、4G/5G 双网络、长时间发热和端到端画面延迟测试。本次未承诺 4K 与 60 FPS 可同时持续达到；25 FPS 实测未达目标，已如实记录。网络 RTT 不等于屏幕端到端延迟。
