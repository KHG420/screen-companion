# 同屏 0.2.0 验证记录

日期：2026-09-25。范围：电脑浏览器与 Android 10+ 双人房间。iOS、多人、LiveKit/SFU 不在本版范围。

## 实现与交付

- 电脑使用原生 ES 模块，不新增运行时依赖；与安卓共用既有 Go v1 房间、信令及共享互斥协议。
- WebRTC 设备直连优先，现有 coturn 作为备用。此次跨端验收实际选择了 TURN，中转 RTT 约 45–117 ms；这是网络往返统计，不能当作画面端到端延迟。
- 奶油/棕色首页、深蓝/奶黄色通话界面。使用批准角色稿重绘的两张独立透明互动素材。共享画面时隐藏大插画。
- 网页标题使用自托管 ZCOOL KuaiLe 中文标题子集，OFL 许可证随包保留。
- 安卓版本 0.2.0，versionCode 3，同一测试签名，可覆盖安装旧版。

## 验证边界

本机 Mac 没有可用麦克风，桌面音频输入测试使用正弦波替代，未验证物理麦克风、扬声器回声消除效果。电脑共享测试包含受控 Canvas 输入，原生 getDisplayMedia 已验证选择器及取消流程，未声称整屏/窗口/标签页真实音频采集均通过。

未完成 Windows/Linux 实机、不同品牌 Android 真机、4G/5G 双网络、蓝牙耳机、长时间发热与端到端屏幕延迟测量。两台 Android 官方模拟器不能替代上述真机验收。历史 Android 内部媒体音频测试见原测试记录，本版未改动该采集链路。

本机无 STUN/TURN 的纯 host/mDNS 浏览器试验未连接；接入现有公网 ICE 服务后测试通过。不据此宣称所有本地网络直连都已验证。

## 重现入口

本地 Go：LISTEN_ADDR=127.0.0.1:18765 go run .（server 目录）。项目根目录：python3 scripts/serve-web.py。开发页 /tests/browser.html 仅用于测试，不部署到公网。生产只发布 index.html、style.css、app.js、call.js 及 assets；网页入口由部署者配置。

web/tests/ui.html 为实际界面验证专用夹具，仅替换麦克风输入，不属于生产客户端。
