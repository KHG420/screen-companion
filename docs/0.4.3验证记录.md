# 0.4.3：以真实 4K60 为目标

## 改动与取舍

- 新增 4K · 60 帧预设：长边 3840、短边 2160、60 FPS、40 Mbps 上限，保持分辨率优先。不会为通过帧率指标而把目标改成 1080p，低分辨率采集源仍不放大。
- 高于 30 FPS 时使用动态内容编码提示，和“资源不足时优先保分辨率”独立。原有 4K30/文字清晰继续走细节内容路径。
- 网页在第一帧附着到发送器前设置采集约束及发送码率/帧率，避免先用默认参数启动再改。
- 网页按每个已提供的 H.264 profile/packetization 配置探测 4K60 编码与解码能力；优先可平滑处理目标的硬件路径，保留全部编码回退。探测失败或不支持该 API 时保留浏览器默认顺序。
- Android 允许 WebRTC 硬件工厂支持的 H.264 High Profile；SDK 自身仍决定哪些设备能启用。未修改媒体协议或增加依赖。

## 测量方法

复用现有 Chrome，真实生成 3840×2160 移动条纹、文字和色块，经两个实际 Call/WebRTC 端点编码、发送、解码与显示。不是给 1080p 图像贴 4K 标签。没有重新启动隔离浏览器或关闭用户的其他应用。

开发页 `web/tests/performance.html` 同时记录：绘图次数、WebRTC 源帧计数、发送/解码 FPS、接收尺寸、呈现帧数、渲染丢帧、编码/解码/排队/缓冲耗时。呈现计数取 `requestVideoFrameCallback` 的 `metadata.presentedFrames`，不把 JS 回调次数当作显示帧数。使用按截止时间调度的定时器，错过截止时间时不积压补画；后台窗口下 requestAnimationFrame 可能暂停，故不用于产生测试源。

稳定性判据：热身 15 秒，再取 10 个 3 秒窗口。只有每个窗口发送与接收均为 3840×2160，且发送、解码、呈现均不低于 57 FPS，才记为“接近 4K60”。这本身也不等于严格恒定 60 FPS。

H.265 虽被系统报告为节能且平滑，但实测出现较大编码排队和缓冲；因此没有只凭 capability 标志把它放到首选。H.264 在短窗口可达到约 57–60 FPS，长时间可能因编码负载降帧。能力声明、短时峰值与持续达标分开报告。

同一台电脑同时生成与接收媒体，且用户其他应用保持运行，结果不是跨设备、隔离条件下的性能保证。真实系统录屏还受原生屏幕像素与刷新率限制。

## Android 验证

两台 Android 35 ARM64 模拟器安装最终 Release APK，使用现有 HTTPS 服务建立通话。共享方把虚拟屏幕设置成 2160×3840，实际发送统计确认 2160×3840；接收端显示共享内容。4K30 → 4K60 热切换、停止共享、挂断及恢复虚拟显示尺寸通过。

模拟器软件编码约 194 ms/帧、2.3 FPS，不能满足 4K60，只证明了真实 4K 采集与功能链路。尚无真机硬件编码的稳定 4K60 验收结果。

## 必要检查

Android Debug/Release 构建、10 项单元测试、两种构建的 lint 通过。13 项 Web 单元测试通过，覆盖首帧配置顺序、4K60 预设、profile 能力探测/缓存/失败回退及探测中挂断；浏览器 17 项实际通话回归通过。

## 最终默认路径的持续测试结果

最终产品代码自动协商到 H.264 `profile-level-id=42001f`；未在该轮手工强制指定编码。热身 15 秒后，连续 30 秒（10 个窗口）保持实际发送/接收 3840×2160：

| 指标 | 平均 | 窗口范围 |
| --- | ---: | ---: |
| 发送 FPS | 49.32 | 38.27–60.83 |
| 接收解码 FPS | 49.39 | 38.60–61.94 |
| 呈现 FPS | 45.49 | 见原始数据 |

累计渲染丢帧 119 帧；未通过“每个窗口均达到 4K 且发送/接收/呈现 ≥57 FPS”的接近目标判据。短周期超过 60 的计数可能来自缓冲释放和窗口边界，不是持续超出 60 FPS 的承诺。原始窗口数据见 `4k60-browser-measurements.json`。

早期对照中，默认 VP8 路径在同一类 4K 动态素材下只有几 FPS；H.264 明显改善了高分辨率吞吐。Main/High Profile 对照也未稳定通过持续判据，因此最终不硬编码所有设备首选 High，而是在可高效处理目标的 profile 中保留浏览器顺序。

结论：已完成面向 4K60 的实现与真实 4K 负载测试；当前环境仍未证明稳定 4K60，不能仅凭预设、能力报告或峰值宣称达标。
