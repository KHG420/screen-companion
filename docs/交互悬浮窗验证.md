# 共享方交互悬浮窗

验证日期：2026-09-26。范围为 Android 共享方；服务端和消息协议没有变化。

## 使用

在通话的“画质与声音”中选择“允许可交互悬浮窗”，在 Android 系统页允许显示在其他应用上层。开始共享后，返回桌面可自动显示；也可使用“悬浮通话与消息”按钮。自动显示与视频显示仍可分别关闭。

- 输入并发送消息，直接查看对方回复；关闭再打开保留本次通话中的草稿。
- 画质提供现有的高清、均衡、文字、流畅四种预设，显示当前目标分辨率和帧率。预设替换当前画质设置，实际编码仍受设备和网络限制。
- 静音/开麦、隐藏/显示视频、停止共享。
- 拖动标题移动，收起为消息提示条，展开恢复操作；右上角关闭仅隐藏窗口。
- 无悬浮窗权限时回退系统画中画，可看消息但不能直接输入。

窗口采用现有深蓝、暖金配色，默认 328×460 dp、收起 236×64 dp，主要按钮至少 44 dp。输入栏和常用操作固定在底部，中间内容可滚动。窗口依据屏幕可见区域调整，键盘弹出时保留输入与发送入口。

## 资源与消息处理

复用 CallService、现有 WebRTC 摄像头轨道、消息通道和画质命令，不创建第二条通话连接，不增加服务器转码或混流。收起、隐藏视频、返回主页面或关闭窗口会移除悬浮预览的 sink 并释放 renderer。消息区最多渲染最近 20 条，完整本次聊天仍由原有主页面管理。草稿只存在当前服务内存中。

消息区被键盘或滚动裁切时，不自动当作已读；标题保留未读数。窗口展开且完整显示消息区时，减少重复系统通知；收起和后台仍使用已有通知机制。
